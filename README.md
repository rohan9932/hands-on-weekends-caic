# Hands-on Weekends — AUSTCAIC

This repo contains code from AUSTCAIC's  hands on weekend sessions on AI/ML — including class exercises, assignments, and related work done as part of the sessions.

## About

CAIC runs weekend sessions focused on learning AI/ML through practical, hands-on coding rather than just theory. This repo serves as a collection of the code written during those sessions, along with assignments assigned as part of the program.

It's meant to track progress and practice over time, so expect a mix of session notebooks, scripts, and assignment solutions at different stages of completion.

## What's inside

- Code from weekly sessions
- Assignment solutions
- Practice exercises and small experiments related to the sessions

## Note

This is a learning-focused repo, so code style and completeness may vary across files. Contributions or suggestions from fellow club members are welcome.
